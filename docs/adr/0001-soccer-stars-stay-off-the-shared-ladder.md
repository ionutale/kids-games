# Soccer stars stay off the shared ladder

Soccer remembers the best Star count per level on its own level steps. The shared ladder stays a level number plus a mastery flag for every ladder game. Putting stars on the shared ladder would make every other game look unfinished, and Soccer is the only game that earns them.

**Update 2026-11-07:** the star row now lives on the Soccer page above the shared ladder (a local row), not on the LadderBar steps. The decision — stars stay off the shared ladder — is unchanged.
