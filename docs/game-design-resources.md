# Game Design Learning Resources

Curated free sites explaining best practices for 2D games, menus/UI, sound, and graphics.
Companion to [free-assets.md](free-assets.md) (which covers *where to get assets*; this covers *how to use them well*).

## Game Design (general)

- **[GDC YouTube channel](https://www.youtube.com/@Gdconf)** — free conference talks; the single best resource. Search for "game feel", "juice", "designing games for kids".
- **[Game Programming Patterns](https://gameprogrammingpatterns.com)** — Bob Nystrom's free online book on engine/architecture patterns (state machines, object pools, event queues).
- **[Lost Garden](https://lostgarden.com)** — Daniel Cook's classic essays on game design and art direction.
- **[Deconstructor of Fun](https://www.deconstructoroffun.com)** — teardowns of why popular games work.

## Game Feel / Juice

Directly relevant to snap/nudge/celebration polish in this repo's games:

- **"Juice it or lose it"** — Martin Jonasson & Petri Purho (YouTube) — how small feedback effects make interactions satisfying.
- **"The Art of Screenshake"** — Jan Willem Nijman (YouTube) — 20 minutes on making actions feel impactful.
- **[masahiro sakurai on creating games](https://www.youtube.com/@MasahiroSakuraiOnCreatingGames)** — short videos on feel, difficulty, and feedback from the Smash Bros creator.

## Menus / UI / Touch UX

Critical since these games are touch-first for kids:

- **[Game UI Database](https://www.gameuidatabase.com)** — 30k+ searchable screenshots of real game menus/HUDs; the go-to reference.
- **Apple Human Interface Guidelines** ([developer.apple.com/design](https://developer.apple.com/design/human-interface-guidelines)) — touch target sizes, safe areas, gesture conventions.
- **Google Material Design** ([m3.material.io](https://m3.material.io)) — same, Android-flavored.

## Sound Design

- **[Designing Sound](https://designingsound.org)** — articles on game audio craft.
- **[GameSoundCon](https://www.gamesoundcon.com)** — publishes free session summaries/reports on game audio practice.

## Graphics

- **[Lospec](https://lospec.com)** — pixel-art tutorials + palettes.
- **Pedro Medeiros "Saint11" pixel art tutorials** — legendary animated technique guides (search "saint11 pixel tutorial").
- **[OpenGameArt forums](https://opengameart.org/forums)** — practical WIP critiques.

## Kids-Specific UX

- GDC has dedicated talks ("Designing Games for Kids", "Designing Touch Interfaces for Toddlers") — search the GDC channel.
- **Sesame Workshop research briefs** — free studies on young children's touch interfaces (search "sesame workshop digital design research").
