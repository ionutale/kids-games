# 05 — Category Sort: Content Growth

## What to build

Keep a returning five-year-old surprised. Add at least three categories with eight SVG items each, and introduce mixed sets for late levels so a round can combine closer topics. Four Homes stays the ceiling; every Home still receives at least one item.

## Acceptance criteria

- [ ] At least three new categories, each with eight SVG items
- [ ] New categories join the 2-, 3-, and 4-home set pools
- [ ] Late levels use mixed sets that make the child think about each item
- [ ] Four Homes remains the maximum
- [ ] Every Home gets at least one item in every round
- [ ] Item distribution stays balanced (bins differ by at most one)
- [ ] Unit tests cover set validity, id resolution, and balance with the new categories
- [ ] An e2e pass at a late level proves the bigger content still fits
- [ ] No new dependencies
