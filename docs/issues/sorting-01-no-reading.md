# 01 — Sorting: No Reading Required

## What to build

Remove the last thing that assumes reading. The sentence hint becomes a visual cue: a pointing hand and arrow that first say "pick an item", then "put it in a basket", with the localized sentence kept as a small caption for adults. On the first round of level 1, a ghost hand demonstrates one correct placement so a child can copy the gesture without instructions.

## Acceptance criteria

- [ ] The hint is carried by a pointing hand / arrow animation, not a sentence
- [ ] The localized sentence remains as a small caption (all six locales)
- [ ] Level 1, round 1 demonstrates one correct placement with a ghost hand
- [ ] Tapping during the demonstration dismisses it and leaves the board playable
- [ ] A pre-reader can complete a round with no spoken or written instruction
- [ ] Hint and demonstration behave under `prefers-reduced-motion`
- [ ] Behavioral or e2e coverage for the hint state and the demo dismissal

## Blocked by

None — can start immediately
