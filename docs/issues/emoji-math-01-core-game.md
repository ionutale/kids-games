# 01 — Emoji Math: Core Game + Hub + Tests

## What to build

The full Emoji Math game: emoji-count equations with 4 multiple-choice answers. Difficulty adapts to global age setting. Endless practice with milestone celebrations at 10 correct answers.

Files:
- `src/routes/games/emoji-math/+page.svelte`
- `src/routes/games/emoji-math/+page.js`

## Acceptance criteria

- [ ] Equations display as emoji counts (e.g., 🍎 + 🍎 = ?)
- [ ] 4 multiple-choice answer buttons displayed below equation
- [ ] Correct answer highlighted green + chime
- [ ] Wrong answer shakes + shows correct answer
- [ ] Difficulty matches age setting (age 2-3: counting, age 4: add ≤10, age 5+: add ≤20)
- [ ] 10 correct answers triggers milestone celebration
- [ ] Running correct count / streak displayed
- [ ] Home button to exit
- [ ] Game appears in hub with icon
- [ ] Translation keys for all 3 languages
- [ ] CONTEXT.md updated
- [ ] Unit + behavioral + E2E tests pass

## Blocked by

None — can start immediately
