# 01 — Cozy Memory: Scene and Persistent Pairs

## What to build

Turn the memory board from a cold starry grid into a warm evening table. Cards become wooden blocks with a moon back and cream faces, the page gets a lantern glow and fireflies over a dimmed starfield, and matched pairs stay on the board as a settled collection instead of vanishing and leaving holes.

## Acceptance criteria

- [ ] Warm night palette replaces the icy cyan accents on this page only
- [ ] Cards have wooden backs with a moon motif, cream faces, and no bare `?`
- [ ] Lantern glow and fixed-position fireflies render without hydration mismatch
- [ ] Matched pairs stay visible with a warm ring; the grid never develops holes
- [ ] The win overlay reads cream and amber, with a moon-and-bear badge
- [ ] Hidden hooks survive: `.card`, `.card-front`, `.flipped`, `.matched`, `.level-label`
- [ ] Existing memory tests are updated and passing
