# 02 — Sorting: More Worlds, Real Curve

## What to build

Levels 6–10 currently repeat: the game caps at 8 items and 4 baskets from level 4, and only colours and shapes exist. Add themes with their own SVG sets (fruit and vegetables, animals and vehicles, land / sea / sky), introduce a three-basket step, grow the item count toward 10–12 at the top, and guarantee that every visible basket receives at least one item in a round.

## Acceptance criteria

- [ ] At least five themes, including colours and shapes
- [ ] Every new item uses SVG art, never emoji
- [ ] Shape-style themes use a single hue so colour is never a second rule
- [ ] Level curve: 2 baskets at 1–3, 3 baskets at 4–5, 4 baskets at 6–10
- [ ] Item count grows meaningfully and reaches 10–12 by level 10
- [ ] Every basket gets at least one item per round
- [ ] The ladder and saved-progress keys are unchanged
- [ ] Unit tests for round building and item distribution
- [ ] A late-level e2e pass proves the larger board stays usable

## Blocked by

None — can start immediately
